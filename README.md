# 🎬 CineBook – Movie Ticket Booking System

CineBook is a web-based movie ticket booking application developed using Python Flask, SQLite, HTML, CSS, and JavaScript. It provides users with an interactive platform to explore movies, select seats, and book movie tickets through a simple and user-friendly interface.

## ✨ Features

- **User Authentication:** Secure registration and login functionality.
- **Movie Listings:** Browse movies with posters, ratings, languages, categories, and ticket prices.
- **Movie Search:** Search for movies by title.
- **Category Filtering:** Filter movies by genres such as Action, Comedy, Drama, and Sci-Fi.
- **Seat Selection:** Select seats for your preferred movie show.
- **Ticket Booking:** Book tickets by selecting the show date, showtime, and seats.
- **Booking Confirmation:** View booking confirmation details, including booking reference, selected seats, show information, and total amount.
- **My Bookings:** Access personal booking information.
- **Database Integration:** Store user accounts and booking records using SQLite.

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python, Flask
- **Database:** Mysql
- **Authentication:** Password hashing and session-based authentication
- **Tools:** Visual Studio Code, Git, GitHub

## 🎯 Project Objective

The objective of CineBook is to develop a simple and interactive online movie ticket booking system that demonstrates full-stack web development concepts, including frontend design, backend development, database management, user authentication, and booking workflows.
